# Автотесты для Tutu.ru

Учебный проект с UI-автотестами для сайта [Tutu.ru](https://www.tutu.ru/). Тесты написаны на Java с использованием Selenide и JUnit 5; результаты формируются в Allure Report.

## Технологии

- Java 21
- Gradle
- JUnit 5
- Selenide
- Allure Report
- Jenkins
- Allure TestOps

## Проверяемые сценарии

| № | Тест-кейс |
| --- | --- |
| 1 | Открывается главная страница |
| 2 | На главной странице видна шапка сайта |
| 3 | На главной странице есть meta description |
| 4 | На главной странице виден логотип |
| 5 | На главной странице видна форма поиска |
| 6 | На главной странице есть кнопка «Войти» |
| 7 | На главной странице виден футер |
| 8 | Открывается страница справочной |
| 9 | Открывается страница путеводителя |
| 10 | Открывается страница ЖД-билетов |

## Запуск

Локальный запуск:

```bash
./gradlew clean test
```

В Jenkins тесты запускаются в удалённом Chrome через Selenoid. После выполнения Jenkins публикует Allure Report.
